## 🚀 快速配置步骤

### 步骤1: 获取Memo0 API Key

1. 访问 https://platform.mem0.ai
2. 注册账号或登录
3. 进入API Keys页面
4. 创建新的API Key
5. 复制API Key（格式类似：`mem0-xxxxxxxxxxxxx`）

### 步骤2: 配置API Key

#### 方法1: 环境变量配置（推荐）

创建或编辑 `.env` 文件：

```bash
# Memo0 配置
MEM0_API_KEY=your_mem0_api_key_here
MEM0_USER_ID=crypto-arbitrage-v52-user
MEM0_AGENT_ID=trading-bot-v52
```

#### 方法2: 配置文件配置

编辑 `config/config.yaml` 文件：

```yaml
mem0:
  api_key: "your_mem0_api_key_here"
  user_id: "crypto-arbitrage-v52-user"
  agent_id: "trading-bot-v52"
  rerank: true
  keyword_search: false
  top_k: 10
  score_threshold: 0.7
  cache_ttl: 300
```

## ⚠️ 常见问题排查

### 问题1: Memo0连接失败

**错误信息**:
```
❌ Memo0初始化失败: API Key无效
```

**解决方案**:
1. 检查API Key是否正确复制（无多余空格）
2. 确认API Key是否有效且未过期
3. 检查网络连接是否正常
4. 验证Memo0服务是否可用

### 问题2: 降级到SQLite模式

**错误信息**:
```
⚠️ Memo0状态: SQLite降级模式
```

**解决方案**:
1. 检查`.env`文件中的`MEM0_API_KEY`是否设置
2. 检查`config/config.yaml`中的`mem0.api_key`是否设置
3. 确认环境变量优先级正确（环境变量 > 配置文件）

### 问题3: 语义搜索不工作

**错误信息**:
```
⚠️ 语义搜索功能不可用
```

**解决方案**:
1. 确认`mem0.semantic_search.enabled`设置为`true`
2. 检查Memo0 API版本是否支持语义搜索
3. 验证相似度阈值设置是否合理（0.5-0.8）

### 问题4: 性能问题

**症状**: 响应速度慢，超过3秒

**解决方案**:
1. 增加`cache_ttl`值（300-600秒）
2. 减少`top_k`值（5-10）
3. 启用`rerank`以提高准确性
4. 检查网络延迟
