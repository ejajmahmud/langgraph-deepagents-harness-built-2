# 多种恢复操作类型
class RecoveryActionType(Enum):
    RESTART_COMPONENT = "RESTART_COMPONENT"  # 重启组件
    CLEAR_CACHE = "CLEAR_CACHE"  # 清除缓存
    RESET_CONNECTION = "RESET_CONNECTION"  # 重置连接

### 3. 备份管理器（BackupManager）

**文件**: `ops/backup_manager.py` (550+ 行)

**核心功能**:
- ✅ **全量和增量备份** - 灵活的备份策略
- ✅ **自动备份调度** - 定期自动备份
- ✅ **压缩和加密** - 优化存储和安全性
- ✅ **一键恢复** - 快速恢复数据
- ✅ **备份验证** - SHA256 校验和验证

**技术亮点**:
```python
# 创建备份
metadata = await manager.create_backup(
    sources=['data/', 'config/'],
    backup_type=BackupType.FULL,
    compress=True
)

# 恢复备份
result = await manager.restore_backup(
    backup_id=metadata.backup_id,
    restore_to=restore_dir,
    overwrite=True
)

# 定期备份
await manager.schedule_backup(
    sources=['data/'],
    interval_hours=24,
    backup_type=BackupType.FULL
)

# 清理旧备份
await manager.cleanup_old_backups(keep_days=30, keep_count=10)
```

**实际效果**:
- 支持全量和增量备份
- 自动压缩（gzip）
- SHA256 校验和验证
- 自动清理旧备份
- 备份元数据管理
