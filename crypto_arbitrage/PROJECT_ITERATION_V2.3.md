## 使用示例

### 1. 快速部署
```bash
# 1. 配置环境变量
cp .env.example .env
nano .env  # 编辑配置

# 2. 启动服务
./deploy.sh setup
./deploy.sh start

# 3. 查看状态
./deploy.sh status
./deploy.sh logs

# 4. 健康检查
python scripts/health_check.py
```

### 2. 带监控的完整部署
```bash
# 启动监控服务
docker-compose --profile monitoring --profile cache up -d

# 访问Grafana仪表盘
# URL: http://localhost:3000
# 用户名: admin
# 密码: admin123
```

### 3. 生产运维
```bash
# 数据备份
./deploy.sh backup

# 更新代码
git pull origin main
./deploy.sh update

# 查看健康状态
./deploy.sh health

# 查看告警
tail -f logs/alerts/alerts_*.log
```

